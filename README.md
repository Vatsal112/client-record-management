# Client Record Management

## Installation and Setup

Follow these steps to set up and run the project:

### 1. Clone the Repository

```bash
git clone git@github.com:Vatsal112/client-record-management.git
```

### 2. Navigate to the Project Directory

```bash
cd client-record-management
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will start, and you can access it in your browser at the URL displayed in the terminal (e.g., `http://localhost:5173`).
